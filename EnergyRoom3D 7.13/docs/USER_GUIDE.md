# EnergyRoom 3D — user guide

This guide explains how to use the project in a simple, goal-oriented way.

## 1. Start with the building

The first step is to design the home. Decide:

- number of rooms
- layout and level structure
- walls, openings, and roof geometry
- whether the design is fully free-form or assisted by the system

A well-planned building layout influences solar access, internal heat balance, and installation cost.

## 2. Add devices and loads

Once rooms exist, add household appliances and equipment. The simulator focuses on realistic load behavior rather than perfect abstraction.

Examples:

- kitchen appliances
- heating and ventilation devices
- energy-intensive white goods
- entertainment and office equipment

The goal is to match the real-life behavior of devices across the day.

## 3. Add generation and storage

The next step is to add photovoltaic generation and storage.

Typical decisions:

- roof area available for PV
- panel orientation and slope
- battery size and reserve level
- how much energy should stay available for nighttime or outages

This stage determines whether the home is energy-positive or strongly dependent on grid import.

## 4. Review installation and safety

The electrical layer is critical. It tracks:

- sockets and power distribution
- cable lengths and resistance losses
- circuit protection and breaker behavior
- main switch and fault scenarios

This means the project is not just a visual simulation — it also models practical engineering constraints.

## 5. Run the simulation

When the design is ready, run the simulation and look at:

- total energy consumption
- generation from PV
- battery charge/discharge behavior
- grid import/export
- power peaks and bill impact

The simulator is most useful when comparing scenarios, not only reading a single final number.

## 6. Improve the setup

Most users will iterate several times:

- move the PV panels to better roof surfaces
- reduce shading from other objects
- add a better battery reserve strategy
- rebalance device placement and peak loads
- inspect the cost of wiring and protection

## Good questions to ask during design

- Where is the best solar area on the roof?
- Which devices produce the sharpest evening peaks?
- Does the battery reserve leave enough room for flexible use?
- Are the current protections sized correctly for the circuit?
- Does the room layout reduce or increase the need for long cable runs?

## Recommended beginner scenario

A good entry point is:

1. add a small residential layout
2. place a few key appliances
3. install a modest PV array
4. attach a battery
5. run the simulation for a full day cycle
6. compare results before and after adding more solar or storage

This will quickly reveal the relationship between design choices and energy outcomes.
